# FizzBuzz (1〜50) Web アプリケーション

1から50までの数値を判定し、視覚的にわかりやすく表示するシンプルな FizzBuzz Web ページです。

---

## 概要

本プロジェクトは、1〜50の範囲で FizzBuzz を計算・可視化するフロントエンドアプリケーションです。
外部ライブラリに依存せず、単一の HTML ファイル（HTML / CSS / JavaScript）のみで動作します。

---

## 主な特徴・機能

- **FizzBuzz ルールに基づく自動判定**:
  - **FizzBuzz**: 15 の倍数（3 と 5 の公倍数）
  - **Fizz**: 3 の倍数
  - **Buzz**: 5 の倍数
  - **数字**: それ以外の数値
- **カード・グリッドデザイン**:
  - レスポンシブ対応のタイルレイアウト
  - 種別ごとに色分けされたバッジ表示（FizzBuzz: 紫、Fizz: 青、Buzz: 琥珀、数字: グレー）
  - ホバー時のアニメーション効果
- **インタラクティブな絞り込みフィルター**:
  - 「すべて」「FizzBuzz」「Fizz」「Buzz」「数字のみ」をワンクリックで切り替え可能
  - 上部に各分類の該当件数をバッジで表示
- **ゼロ依存・軽量**:
  - フレームワークや外部ライブラリを一切使用しない Vanilla JavaScript / CSS 実装

---

## 画面イメージ・内訳（1〜50）

| 区分 | 件数 | 該当する数値（例） |
| :--- | :--- | :--- |
| **すべて** | 50件 | 1 〜 50 |
| **FizzBuzz** | 3件 | 15, 30, 45 |
| **Fizz** | 13件 | 3, 6, 9, 12, 18, 21, 24, 27, 33, 36, 39, 42, 48 |
| **Buzz** | 7件 | 5, 10, 20, 25, 35, 40, 50 |
| **数字のみ** | 27件 | 1, 2, 4, 7, 8, ... |

## 使い方

特別なビルド手順や環境構築は不要です。

1. 本リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone git@github.com:siyu198/1118-fizzbuzz.git
   cd 1118-fizzbuzz
   ```
2. `index.html` をお好みのブラウザでダブルクリックして開きます。
   （VS Code の Live Server や Python の `http.server` などのローカルサーバー経由でも問題なく動作します）
